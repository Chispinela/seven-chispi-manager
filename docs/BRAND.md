# AI assistance and visual identity

**Seven Chispi Manager was developed with extensive AI assistance using ChatGPT and Codex.** AI was used for implementation, code review, documentation, and test preparation. Human direction, review, and real-world validation remain necessary. AI assistance is not evidence that every feature or integration is correct.

The original application logo was generated with OpenAI ImageGen. The final asset is `assets/logo.png`; `assets/icon.ico` is the Windows icon export. The splash screen uses the same logo with floating motion, orbits, and an animated activity bar, and respects the system preference for reduced motion.

Original image prompt:

> Use case: logo-brand. Asset: app icon for Seven Chispi Manager, a modern Windows server manager for 7 Days to Die. Create a premium crisp square emblem, a stylized angular number 7 integrated into a fortified hexagonal shield with subtle server-rack bars, luminous violet and lavender metal, dark plum charcoal background. Minimal striking silhouette legible at small sizes, restrained dimensional bevel and purple edge light, professional gaming utility branding. Centered with generous safe margin, no letters or words, no watermark. 1024 square.
